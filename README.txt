KALP TOURS & TRAVELS - Android + iPhone PWA

1. index.html, style.css, app.js અને manifest.json ને એક જ ફોલ્ડરમાં રાખો.
2. index.html ને વેબ હોસ્ટિંગ પર HTTPS સાથે publish કરો.
3. Android Chrome માં Add to Home Screen / Install App પસંદ કરો.
4. iPhone Safari માં Share > Add to Home Screen પસંદ કરો.
5. WhatsApp/Call નંબર index.html અને app.js માં 919999999999 ને તમારા સાચા નંબરથી બદલો.

આ વર્ઝન મૂળભૂત MVP છે. આગળ Online Payment, Admin Panel, Tour Photos, Booking Database, Push Notifications અને Play Store/App Store packaging ઉમેરી શકાય.
